Polymarket 跟单常见问题

Polymarket 能跟单吗？怎么跟？

+

能，但 Polymarket 本身没有跟单功能，需要第三方工具盯住目标钱包的成交再按比例下单。Wakeloom 第一期只做模拟盘：选定钱包、设好比例和上限，它成交时我们按当时盘口模拟成交，并记录价差。

怎么判断一个 Polymarket 交易者是不是长期表现稳定？

+

看足够长的窗口和足够多的已结算市场，而不是单笔大赚。我们用近 90 天数据，同时看胜率、收益率、最大回撤和收益是否集中在一个事件上，样本太少或靠一次重仓的地址不进榜。

Polymarket 排行榜第一名值得跟吗？

+

不一定。按金额排的榜首常常是一次重仓押中，或者成交量里有大量刷量和做市对冲，这类表现很难复制。我们的排行榜先排除这些地址，再按长期表现排序，但上榜也不代表以后还会这样。

跟单 Polymarket 会不会因为延迟和滑点亏钱？

+

会。我们发现对方成交到自己下单之间有延迟，价格可能已经变了，薄盘口还会吃到更差的价。所以每一笔都记录和对方的成交价差，偏离超过阈值就放弃，先在模拟盘里算清楚扣掉成本后的结果。

Wakeloom 会托管我的私钥吗？

+

第一期只有模拟盘。Wakeloom 不接收、不托管用户私钥。钱包登录只签署登录接口返回的那段文案（例如 Sign in to Wakeloom.），该签名不能用来转账，也不能授权交易。

胜率和收益率哪个更重要？

+

单看哪个都不够，要结合买入价格和回撤一起看。在 90¢ 买入的高胜率可能一次失手就抹掉多次收益，低胜率但买得便宜的人也可能长期为正，所以我们同时展示胜率、收益率、最大回撤和平均买入价。

对方平仓了我怎么办？

+

跟着平。跟单规则里对方减仓或平仓时，我们按同样比例减仓或平仓。一键暂停所有跟随的全局停止即将推出。

数据从哪来？多久更新？

+

来自 Polygon 链上成交记录和 Polymarket 的公开接口。排行榜和详情页打开时会向公开接口拉取最新数字；构建进仓库的是 SEO 用的快照。拿不到的数据显示「无数据」，不会用 0 填充；页面会写明数据截至时间（北京时间）。

跟单有风险吗？会亏钱吗？

+

有风险，也会亏钱。过去的表现不代表以后，对方可能改变风格或判断失误，延迟和手续费也会吃掉一部分结果。所以第一期只开放模拟盘，详见风险提示。

Wakeloom 和 Polymarket 是什么关系？

+

没有隶属或合作关系。Wakeloom 是用于 Polymarket 的独立分析工具，只读取公开的链上和接口数据。
