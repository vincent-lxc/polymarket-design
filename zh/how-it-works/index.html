首页 / 选人方法

我们怎么挑值得跟的 Polymarket 交易者

Wakeloom 的选人规则与统计口径：近 90 天窗口、已结算市场、回撤、集中度，以及排除单次重仓、刷量和做市地址的方法。

统计口径

统计窗口是近 90 天，只算已经结算的市场。每个地址展示胜率、收益率（已实现加浮动，除以投入）、最大回撤、已结算市场数、平均买入价、单笔中位金额和持仓中位时长。

成交笔数太少的地址样本太小，不生成详情页。

先排除，再排序

单次重仓：收益大部分来自同一个事件的地址会被排除，这种结果靠运气的成分太大。

刷量与自成交：成交量远大于收益、或者出现自己和自己成交的地址会被排除。

做市：双边挂单比例高的地址赚的是价差，跟着它的方向下单复制不了，也会被排除。

通过筛选的地址再按长期表现综合排序。排序用的综合分是内部指标，不对外公布。

数据来源与更新

成交来自 Polygon 链上记录和 Polymarket 公开接口。排行榜和详情页由浏览器请求公开接口刷新数字；仓库里的 HTML 是 SEO 快照。每页写明数据截至时间（按你浏览器的本地时区显示）。拿不到的数值显示「无数据」，不用 0 填充。

限制

过去 90 天的表现不代表以后。筛选规则能去掉明显的噪音，但去不掉所有运气，也看不到地址背后的人是否改变了策略。
