首页 / 选人方法

我们怎么挑值得跟的 Polymarket 交易者

Wakeloom 的选人规则与统计口径：近 90 天窗口、已结算市场、回撤、集中度，按综合评分排序。

统计口径

统计窗口是近 90 天，只算已经结算的市场。每个地址展示胜率、收益率、最大回撤、已结算市场数、平均买入价、单笔中位金额和持仓中位时长。

收益率 = 已实现盈亏 ÷ 投入，不含未结算持仓的浮动盈亏。目前多数地址的数据来自第三方，收益率用对方给的数字，口径可能不同。

成交笔数太少的地址样本太小，不生成详情页。

先打分，再排序

Wakeloom 用收益集中度、刷量等门槛给地址打分，没通过的地址没有综合评分；被识别为疑似做市的地址不参与排名。目前多数地址的数据来自第三方，还没做这几项检查，请自己再看一下。

通过筛选的地址按综合评分排序。胜率和收益率会列在榜上，但不是排序依据。官网公开榜和 App 排行读同一份公开榜，数据截至时间一致。

数据来源与更新

成交来自 Polygon 链上记录和 Polymarket 公开接口。排行榜和详情页由浏览器请求公开接口刷新数字；仓库里的 HTML 是 SEO 快照。每页写明数据截至时间（按你浏览器的本地时区显示）。拿不到的数值显示「无数据」，不用 0 填充。

限制

过去 90 天的表现不代表以后。筛选规则能去掉明显的噪音，但去不掉所有运气，也看不到地址背后的人是否改变了策略。
