跟单前该看哪些数据：样本量、回撤和收益集中度

跟单一个 Polymarket 交易者之前，先看三个数：一共有多少已结算市场、最大回撤有多大、收益是不是集中在一两个事件上。这三项过关，再看胜率配平均买入价、单笔金额和持仓时长，最后确认数据截至什么时候。下面按这个顺序逐项说明。

已结算市场数：样本够不够

这是最先看的一项。已结算市场数说的是这个地址参与过、并且已经出结果的市场有多少个，按全部历史算。

没结算的市场，盈亏还只是账面数字，价格变了就跟着变。只算已结算的市场，看到的才是确定下来的结果。

样本越少，胜率和收益率越容易被一两次结果带偏。具体多少才够，没有放之四海皆准的数字，可以拿同一个榜上的人互相比较。两个人收益率差不多，已结算市场多出几倍的那个，数字更可信。

Wakeloom 的已结算市场数按全部历史算，胜率和收益率按近 90 天算，成交笔数太少的地址不生成详情页。

最大回撤：你拿不拿得住

最大回撤是账户从高点往下跌得最深的一次，用百分比表示。它回答的是：跟这个人，最难受的时候会是什么样子。

两个收益率接近的人，回撤小的那个走得更平。回撤大的人可能最后也赚了，但中途跌得很深。你按比例跟着他，账户也会经历差不多的下跌，很多人会在这个时候停手，刚好错过后面的回升。

看回撤的时候，最好问自己一句，这个跌幅放在自己账户上，能不能接受。

收益集中度：拿掉最赚的一场还剩多少

这一项最容易被忽略。做法很简单，看这个地址的收益里，最大的一笔或一个事件占了多少。把它拿掉，剩下的部分还是不是正的。

如果大部分收益来自同一个事件，它的成绩主要是那一次押对了。这样的结果很难重复，跟单时面对的都是新的事件。

Wakeloom 用收益集中度、刷量等门槛给地址打分，没通过的地址没有综合评分。这几项检查还在补全，看任何排行榜，包括 Wakeloom 的，都建议按这个思路自己算一遍。

胜率和平均买入价：一起看才有意义

单看胜率容易误判。Polymarket 的价格可以看成市场给出的概率，一份合约结果为真时兑付 1 美元（USDC）。在 90¢ 买入，押中每份赚 10¢，押错每份亏 90¢；在 30¢ 买入，押中每份赚 70¢，押错每份亏 30¢。

所以高胜率配高买入价，可能一次失手就抹掉很多次收益。低胜率配低买入价，长期也可能是正的。胜率旁边一定要看平均买入价。胜率和收益率哪个更重要？单看哪个都不够，要结合平均买入价和最大回撤一起看，详见常见问题。

收益率：先弄清口径

不同网站的收益率算法不一样。有的只算已实现，有的把未结算持仓按当前价格算进去，分母也有用投入金额、也有用账户余额的。

Wakeloom 自己计算收益率时，用已实现盈亏 ÷ 投入，不含未结算持仓的浮动盈亏。比较两个地址时，要确认数字来自同一个口径、同一个截至时间。

单笔金额和持仓时长：你能不能照着做

单笔中位金额能看出这个人一般下多大的注。和自己的资金比一比，就知道按比例跟要下多少，是否会小到不值得、或者大到超出自己的上限。

持仓中位时长能看出他的节奏。持仓时间短、进出快的人，你看到他成交再下单，价格可能已经变了，跟单结果和他本人的差距会更大。持仓时间长的人，这个影响相对小一些。

数据截至时间（as_of）：别拿旧数据做判断

每个数字都要配一个截至时间。榜单上的名次和详情页上的数据，如果截至时间不同，放在一起比就没有意义。

Wakeloom 的排行榜和每个 leader 详情页都标明数据截至时间，官网和 App 读同一份数据。拿不到的值显示「无数据」，不用 0 填充，看到「无数据」时不要把它当成 0。

看完数据以后

这些数据说明的都是过去。对方可能换打法，也可能判断失误，回撤以后不一定还在原来的范围里。

比较稳妥的做法是先用模拟盘跟一段时间，看扣掉价差、延迟和手续费以后的结果，再决定下一步。Wakeloom 尚未正式上线，现在只做模拟盘跟单分析，结果只供研究，不构成投资建议。

常见问题

跟单前最先看哪个数据？

+

先看已结算市场数。样本太少，胜率和收益率都容易被一两次结果带偏，其他数字也就不太可信。

最大回撤多少算可以接受？

+

没有统一标准，要看自己的承受能力。把这个跌幅放在自己账户上想一想，接受不了就别跟，或者把比例调小。

为什么要看收益是不是集中在一个事件上？

+

收益集中在一个事件上，说明成绩主要来自那一次押对，很难重复。拿掉最赚的一场，剩下的部分还是正的，参考价值更高。

页面上显示「无数据」是什么意思？

+

说明这一项暂时拿不到可靠的数据。Wakeloom 不用 0 填充，「无数据」不等于 0，做判断时应把这一项当作未知。
